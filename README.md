# OFFSCRIPT — Front-End Event Discovery Platform

> **#beoffscript** // The Event Discovery Platform for the Unconventional

Built with Vite, React 19, TypeScript (strict mode), Tailwind CSS, TanStack Router, TanStack Query, GSAP, Motion, and Lenis.

## Quick Start
```bash
cd Client
npm install
npm run dev
```

For complete architectural documentation, design tokens, endpoints configuration, and 3D stage drop-in instructions, see [Client/README.md](Client/README.md).
